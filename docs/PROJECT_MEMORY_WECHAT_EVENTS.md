# 项目持久记忆：微信公众号活动采集

> **记忆标记**：这是本项目的长期上下文记录，提交到 GitHub 作为后续开发和排查的依据。  
> **用途**：后续继续本项目时，先阅读本文件，再决定是否修改抓取、展示和部署逻辑。

## 一. 项目目标

从用户配置的 37 个微信公众号中，自动发现真实的微信公众号文章，筛选其中的技术活动，并展示在个人网站的 `/events/` 页面。

## 二. 不可违反的约束

### （一）真实性

- 只接受真实的 `mp.weixin.qq.com` 公开文章；
- 普通官网、百科、新闻站、活动平台页面不能直接当作公众号文章；
- 文章标题、发布时间、地点、报名链接没有证据时，标记为未公开或未核实；
- 搜索到候选文章不等于活动已经验证；
- 没有可验证文章时，显示真实失败状态，不用假数据填充。

### （二）账号安全

- 不使用个人微信登录；
- 不使用微信读书账号作为采集凭证；
- 不保存微信 Cookie、二维码或登录态；
- 不自动关注公众号、发消息或发布内容；
- 不使用验证码绕过、代理池或账号轮换。

### （三）基础设施

- 采集程序部署在用户已有的阿里云服务器；
- GitHub Pages 负责静态展示；
- GitHub Actions 负责构建和部署；
- 密钥、Token、Cookie 和服务器凭证不能写入 Git、JSON、日志或公开页面。

## 三. 已确认的事实

### （一）搜索发现

- Bing RSS 在当前环境中不稳定，可能返回不可用或非 RSS 内容；
- 百度桌面端 HTTP 请求可能返回安全验证页；
- 搜狗微信搜索结果使用加密跳转链接，直接 HTTP 跟随不稳定；
- 本机 Chrome 无头模式曾成功加载百度移动端动态搜索结果；
- 百度结果中存在查询式微信文章地址：

  ```text
  https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=...&sn=...
  ```

- 旧代码只接受 `/s/随机标识`，会误拒绝上述查询式真实文章地址。

### （二）微信正文验证

- 发现真实文章地址后，仍可能遇到“环境异常”“访问频率限制”或文章不可访问；
- 未读取到正文和时间时，不得把文章发布为已验证活动。

### （三）微信公众号绑定

- 只知道公众号名称，无法保证自动绑定到唯一账号；
- 同名账号、认证名称和机构简称会造成误匹配；
- 首次来源确认可以通过候选文章审核完成，不要求微信登录。

## 四. 已尝试方案及结论

| 方案 | 结果 | 结论 |
|---|---|---|
| Bing RSS | 不稳定或不可用 | 不能作为唯一来源 |
| 百度桌面 HTML | 返回安全验证 | 不能作为唯一来源 |
| 百度移动端普通 HTTP | 可能返回结果，也可能验证 | 需要动态浏览器或降级处理 |
| 搜狗微信 HTML | 结果链接加密 | 可发现但无法保证还原 |
| 用户提供的微信文章地址 | 可能被微信环境拦截 | 仍需正文验证 |
| WeWe RSS | 通常需要微信读书登录态 | 不符合账号安全约束 |
| 付费搜索 API | 能提供结构化结果但收费 | 当前不采用 |
| 本机 Chrome 无头试跑 | 成功发现查询式微信文章地址 | 可作为后续浏览器 worker 方向 |

## 六. 当前状态判断规则

页面上的“0 场活动”必须结合来源统计阅读：

```text
0 场活动 + discoveryUnavailable > 0
  = 搜索入口不可用，不能推断现实中没有活动

0 场活动 + discoveryHits > 0
  = 搜索到了候选，但尚未通过来源或正文验证

0 场活动 + verified = 0 + 所有来源已成功检查
  = 本次检查没有发现符合条件的已验证活动
```

## 七. 后续推荐路线

1. 在阿里云部署无登录、低频运行的浏览器 worker；
2. 依次尝试百度移动端、搜狗微信和 Bing 中文 HTML；
3. 统一解析 `/s/标识` 与 `/s?__biz=...` 两种文章地址；
4. 文章正文不可访问时保留候选和失败原因；
5. 首次来源确认通过网站配置页面完成；
6. GitHub Actions 只读取云端 JSON、构建和发布，不承担微信登录；
7. 页面同时显示已验证活动、候选文章、不可用来源和最近检查时间。

## 八. 记忆维护规则

- 新尝试必须记录：入口、查询词、请求方式、返回状态、是否拿到真实微信地址、是否通过正文验证；
- 新代码提交必须写明它解决的是“搜索发现”“文章验证”“页面展示”还是“部署”问题；
- 任何“成功”结论都必须附带可复现证据，不能只看 HTTP 200；
- 任何未验证数据都不能进入已发布活动列表。
